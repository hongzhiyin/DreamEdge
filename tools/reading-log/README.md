# 阅读记录工具

这是 DreamEdge 第一阶段的手工样例，使用框架存储接口，不直接访问文件、数据库或模型。

已有功能：添加日期、阅读内容、分钟时长；按日期倒序显示记录；统计记录数、累计分钟和阅读天数；确认后删除；重启后继续读取原有数据。日期默认取本地日历日期。

数据契约见项目 `docs/architecture.md`。记录保存在本工具的 `entries` 集合。更换界面和构建产物不能覆盖业务数据。

`src/model.ts` 负责数据校验、排序和统计，`src/useEntries.ts` 负责存储交互，表单和列表各自管理界面交互。样例不含月份筛选；第二阶段通过内置 AI 添加此能力。

独立构建：在项目根目录运行 `npm run typecheck && npm run build:tool -- reading-log`，在宿主点击“重新加载工具”。重新加载会清空未保存的表单草稿，已保存记录保留。
